# 🛠️ DevOps Terraform Roadmap — Official Sample Codebases

## 🚀 Quick Start

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/letstrnsfrm-ai/devops-terraform-roadmap.git
   cd devops-terraform-roadmap
   ```

2. **Navigate to Day 1 Lab**:
   ```bash
   cd day-1-nginx
   terraform init
   terraform apply -auto-approve
   ```

3. **Explore Online Playbooks**:
   Read the full interactive tutorials and enterprise production usecases at:
   - [Day 1 Playbook](https://www.letustransform.com/episodes/terraform-day-1)
